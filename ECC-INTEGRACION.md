# 🤖 Integración con ECC (Everything Claude Code)

## ¿Qué es ECC?

**ECC** es un sistema de optimización de rendimiento para agentes de IA que proporciona:

- ✅ **123+ Skills** reutilizables
- ✅ **69+ Agentes** especializados
- ✅ **78 Comandos** para automatización
- ✅ **Seguridad empresarial** con AgentShield
- ✅ **Multi-lenguaje**: TypeScript, Python, Go, Java, React, Next.js, etc.

**Repositorio**: https://github.com/affaan-m/ECC

## 🔧 Configuración para Mi Despensa

### 1. Instalar ECC en tu proyecto

```bash
# En la raíz del proyecto
npx ecc-universal install --harness claude
```

### 2. Configurar reglas específicas

Crea `.claude/rules/mi-despensa.md`:

```markdown
# Mi Despensa - Reglas Específicas

## Estructura de Componentes

- Usar componentes funcionales con TypeScript
- Implementar animaciones con Framer Motion
- Seguir principios de diseño de Emil Kowalski
- Usar Tailwind CSS para estilos

## Estado

- Zustand para estado global
- localStorage para persistencia
- Supabase para autenticación

## Seguridad

- Validar todas las entradas de usuario
- Usar Row Level Security en Supabase
- Encriptar datos sensibles
- Sanitizar HTML dinámico

## Performance

- Solo animar transform y opacity
- Usar React.memo para componentes puros
- Implementar lazy loading
- Optimizar imágenes
```

### 3. Usar comandos ECC

```bash
# Revisar código antes de commit
/react-review

# Generar tests
/react-test

# Escanear seguridad
/security-scan

# Optimizar performance
/react-performance
```
